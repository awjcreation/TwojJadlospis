# UX / UI — v1.0.8

Dodano pakiet wizualnego dopracowania:

- animacje wejścia widoków,
- glass/blur dla paska nawigacji,
- aktywne ikony jako Material Symbols filled,
- dashboard dnia z datą, nazwą jadłospisu i pierścieniem kalorii,
- empty states dla pustych baz,
- bottom-sheet wygląd menu akcji,
- delikatne hover/elevation,
- ulepszony dark mode,
- układ dwukolumnowy na desktopie dla wybranych widoków.
